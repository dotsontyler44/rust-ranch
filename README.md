# Rust Ranch — Livestock Tracker

A self-contained static website for tracking livestock in Rust. No build tools or server are required.

## Publish free with GitHub Pages

1. Sign in to https://github.com/ or create a free account.
2. Create a **new public repository** named `rust-ranch` (a public repository is required for GitHub Pages on GitHub Free).
3. On the repository page, choose **Add file → Upload files**.
4. Upload `index.html` and `.nojekyll` from this folder. You can also upload this README.
5. Click **Commit changes**.
6. Open **Settings → Pages** in the repository.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch **main** and folder **/(root)**, then click **Save**.
9. Wait a few minutes, then refresh Settings → Pages and click **Visit site**.

Your address will look like `https://YOUR-GITHUB-USERNAME.github.io/rust-ranch/`.

## Data notes

The app stores data in the current browser's local storage. The GitHub Pages website is public, but animal records you add are not automatically uploaded to GitHub and do not sync across browsers/devices. Use **Export data** to save a JSON backup. Do not enter passwords, access codes, or other sensitive information in a public website.
